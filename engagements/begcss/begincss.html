CSS

- CSS stands for Cascading style sheets

Explain the difference between inline, embedded, and external CSS
- inline css is where you write the style directly inside the html tag, embedded css is you write style in the head using the style tag, external css is you write css separately in a css file and link it to your html file
Explain why you should only use external CSS.
- so that the designer can design the web however they want, also its reusability and maintainable
What is a selector used for?
- is used to tell css which html element you want to style
