When should you use a background image, and when should you use the IMG tag?

Use the IMG tag when the image is content: a photo or picture that carries meaning, needs alt text for screen readers and search engines, and should still show if the CSS is missing. Use a background image when it is purely decoration, like a texture, pattern, or small flourish, because CSS can tile, position, and layer it behind text without adding meaning to the page.
