Questions

According to the instructor, what is the main difference between CSS Grid and CSS Flex?

Flex lays out items in one direction at a time, either a row or a column. Grid lays out items in both rows and columns at the same time, so it is better for whole page layouts.

Who decides where a child goes on the page: the child or its parent?

The parent decides. In my layout the container uses grid to give each of the three columns its space, so the columns do not place themselves. Each column then decides how its own children, the grandchildren, are laid out inside it.
