Normal Flow

Block boxes stack from the top of the page to the bottom, and inline content runs from left to right inside each block. Every example below changes that default in a different way.

When a figure is floated, it leaves normal flow and the text wraps around it. The boxes after it move up and fill the space beside it, which can surprise you at first.

Relative

A relatively positioned box moves from where it would normally be, but the space it used to take stays empty. The paragraphs around it do not shift up to fill the gap.

Absolute

An absolutely positioned box is removed from normal flow completely and is placed using top, right, bottom, and left. It scrolls away with the page, and it leaves no gap behind.

Fixed

A fixed box is also removed from the flow, but it is placed relative to the browser window, so it stays on screen while you scroll. Scroll down to watch the fixed picture stay put.

Questions

What is normal flow in HTML?

Normal flow is the default layout. Block boxes stack from top to bottom, and inline content runs left to right inside them, in the same order as the HTML.

What does float do? Why do you need to clear the float?

Float moves a box to the left or right and lets text wrap around it. It takes the box out of normal flow, so the boxes after it move up beside it. Clear makes a box start below the float so headings and other content do not get stuck next to it.

What do absolute, fixed, and relative do?

Relative moves a box from its normal spot but keeps its original space. Absolute removes the box from the flow and places it by top, right, bottom, and left, and it scrolls with the page. Fixed also leaves the flow but sticks to the browser window, so it stays visible when you scroll.

How can you make nice navigation buttons for mobile devices?

Set the links to display: block so each one is a full-width box, then add padding, a background color, and spacing so they are big and easy to tap with a thumb.
